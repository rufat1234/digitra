# DIGITRA - Онлайн Магазин iPhone и Dyson

Полнофункциональный интернет-магазин для продажи iPhone и Dyson с современным интерфейсом и удобной навигацией.

## 🌟 Особенности

✅ **Каталог товаров** - 10 товаров (5 iPhone + 5 Dyson)
✅ **Корзина покупок** - с функцией увеличения/уменьшения количества
✅ **Фильтрация товаров** - по категориям и ценовым диапазонам
✅ **Поиск** - быстрый поиск по названию и описанию товаров
✅ **Оформление заказа** - модальное окно с формой заказа
✅ **Хранилище** - localStorage для сохранения корзины
✅ **Адаптивный дизайн** - работает на всех устройствах
✅ **Красивый UI** - современный дизайн с градиентами и анимациями

## 🔧 Кастомизация

### Изменить товары
Отредактируйте массив `products` в `script.js`:

```javascript
{
    id: 1,
    name: 'Название товара',
    category: 'iphone', // или 'dyson'
    price: 99999,
    description: 'Описание товара',
    icon: '🍎', // Или любой emoji
    rating: 5
}
```

### Изменить цвета
В файле `styles.css` отредактируйте переменные в `:root`:

```css
:root {
    --primary-color: #1e40af;
    --secondary-color: #3b82f6;
    /* ... другие цвета */
}
```

### Изменить контакты
В файле `index.html` найдите раздел "Контакты" и отредактируйте:
- Телефон
- Email
- Адрес

## 📊 LocalStorage

Магазин автоматически сохраняет:
- **Корзину** - все добавленные товары и их количество
- **Заказы** - история оформленных заказов

Данные хранятся в браузере и не требуют сервера.
